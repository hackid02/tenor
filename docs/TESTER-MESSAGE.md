# Getting outside testers

Goal: **10 outside wallets by Nov 13**, so the submission can show real use, not only team QA. Progress is tracked automatically from the chain: run `node scripts/users.js` and read [USERS.md](USERS.md). Nobody has to send an address.

## Where to ask, in this order

1. **Other Buildathon builders** (Mezo Discord, the buildathon channel). Everyone needs testers right now, so offer a swap: you test theirs, they test yours. This gets the most replies.
2. **Mezo Discord, general or testnet channel.** One message, no repeat posting.
3. **Friends and builder group chats** (WhatsApp, Telegram). Send the short DM one by one; a personal ask works far better than a group post.
4. **X**, with the post below. Reply to anyone who asks a question.

When someone tries it, actually test their project back and leave useful feedback.

## Don't

- Don't pay or reward people for transactions, and don't create wallets for friends. Judges can check where a wallet's funds came from, and bought or team-made "users" would hurt more than zero.
- Don't send private keys or ask for them.
